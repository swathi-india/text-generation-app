# Text Generation App

A Python application that generates text from a user prompt using the OpenAI API.

## Features
- Generates text from custom prompts
- Adjustable parameters (max tokens)

## Tech Stack
- Python
- OpenAI API
- python-dotenv

## Setup
1. Clone the repo:
   git clone https://github.com/your-username/text-generation-app.git
2. Install dependencies:
   pip install -r requirements.txt
3. Copy `.env.example` to `.env` and add your OpenAI API key
